# 产品意图

## 目标工作流

用户在 Project DIVA Mega Mix+ 的 PV 鉴赏模式播放 PV，使用 OBS 录制，录制结果已包含清晰的 KTV / ニコカラ风格歌词，无需在后期额外合成字幕。

## MVP 范围

- 基于行级 SRT 时间的同步。
- 显示当前歌词。
- 预显示下一句歌词。
- 下一句在其开始前 3.0 秒出现。
- 有意义的长歌词空白区显示 `...`。
- 底部居中布局。
- 清晰可读的描边与阴影。
- 当前句与下一句具有明确的视觉层级。

## MVP 非目标

- 逐字时间轴。
- 音节时间轴。
- 渐进式卡拉 OK 填充。
- ASS 渲染器或 libass。
- 完整字幕编辑器。
- DLL 热卸载。
- 通用 Mod 框架。

未来想法可以另行记录，但不得自动扩大 MVP 范围。
