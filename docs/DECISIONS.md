# 当前持久决策

| 决策 | 理由 |
| --- | --- |
| 独立维护 DivaKaraoke，保留上游署名和 Git 历史 | 获得上游修改与再分发授权，当前产品已具有独立维护范围 |
| 第二阶段作为公开版本基础 | 保留双轨歌词、注音、行级配色和辅助工具，不混入后续逐字实验 |
| 离线生成数据，运行时读取已验证旁路 | 不为生成工具增加游戏进程内解析或新的逆向入口 |
| 设备路径只存未跟踪的本地配置 | 另一台电脑只修改自己的配置，Agent 读取同一入口 |
| 用户指南、当前规格、历史研究分开 | 用户操作不依赖会话、开发机或排错流水 |
| 日常记录不追加到 STATUS/PLAN/指南 | 这几个文件描述现在，详细过程属于本地报告或有明确范围的变更记录 |
| 发布标签和附件保持不可变 | 修复已发布安装包时用新维护版本，不能让同名包内容漂移 |

历史决策原文保存在归档中，不作为当前状态的替代来源。这里不记录每次小修、测试过程或个人目录。
