## 产物与安装

验收包：artifacts/pv-tools-mvp/DivaPvTools-MVP.zip。包内 MMFreeLyrics.dll 为统一 Release/x64 构建，工具需要 Python 3.11+。包内不含游戏歌词、CPK 或解包资产副本。

关闭游戏，备份游戏 mods/MMFreeLyrics/MMFreeLyrics.dll，再用包内同名 DLL 替换。启动游戏，Ctrl+G 打开“PV 工具”窗口。音频和录制均默认关闭，分别使用各自保存按钮；旧 Ctrl+S 仍保存歌词配置。两项新开关分别保存到 audio-tools.toml、obs-tools.toml。

本轮没有写入游戏目录或启动游戏，安装与游戏内验收由用户执行。独立装载检查只证明 DLL 能被 Windows 加载，不代替 DML/Hook/声音/录像验收。

## 歌词导出器

双击包内 tools/export_lyrics.cmd。本机入口读取已有来源清单和提取树，按当前有效 DML 配置导出，不重新解包、不自动安装。输出在启动器所属目录树的 artifacts/exported-lyrics/cache。

当前有效资料为309首、9个来源零失败；相较历史322少的13首恰好对应当前未启用的 Retro Charts/DLC Songs。详细证据和显式安装命令见 docs/LYRICS_EXPORTER_MVP.md。独立 EXE、智能增量不属于本次 MVP。

## 伴奏模式

选一首标准分轨官方歌曲，播放时切换“伴奏模式 / 关闭人声”：开启应只去除人声，关闭应立即恢复。保存后重启检查开关保留，测试暂停/继续、返回选曲、重播和换曲。若界面显示签名未匹配则功能不可用，不能把它当作成功静音。

四声道歌曲适用；已混入伴奏的人声无法去除。控制层不修改音符判定、分数和 Combo。实际听感、真实 Hook 和恢复行为待用户验收。

## OBS 准备与验收

在 OBS 启用 WebSocket 服务，并配置游戏捕获、录音轨和录像输出路径。复制 tools/obs-helper.example.json 为同目录 obs-helper.json，填入本机 OBS 密码。打开终端，进入解压包根目录运行：

```text
python tools/obs_helper.py
```

游戏 Ctrl+G 工具面板点击“测试 OBS 连接”，连接成功后启用“启用 OBS 联动”和“PV 鉴赏自动录制”，保存设置。

| 操作 | 预期 |
| --- | --- |
| 开始 PV 鉴赏 | 自动启动一次录制，状态显示正在录制 |
| 暂停/继续 PV | 继续录制，不误结束、不重复启动 |
| 自然结束并返回选曲 | 停止并生成独立文件 |
| 中途返回选曲、关闭联动 | 收尾本功能启动的录制 |
| 连续播放两首 | 两个独立视频文件 |
| OBS 预先手动录制 | 本功能跳过，不接管或停止 |
| 游戏退出 | Helper 心跳超时约八秒后尽力收尾本功能录像 |

本版不做预热；请实际检查视频开头是否缺帧、尾部菜单/过渡和音画同步。当前结束依据为返回 PVsel 或离开鉴赏模式，若自然结束驻留画面仍录制，请保留 DLL 旁 obs-runtime.log，需据此补明确结束事件。OBS 断线、强杀 Helper 或启动响应丢失时应在 OBS 中检查并人工收尾；状态会明确提示。
