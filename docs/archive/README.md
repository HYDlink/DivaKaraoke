# 历史研发归档

本目录用于追溯技术调查、旧方案及历史验收，**不是用户指南，也不是当前任务清单**。普通使用请回到[使用文档](../README.md)。

旧文档保留在这里是为了保留有价值的推理和证据，不要求开发者逐篇阅读。只有查历史原因、回归依据或方案取舍时才检索相关文件。

设备绝对路径已替换为变量占位符；未经去标识的原件保存在私有历史备份与 Git 历史。当前路径必须读取自己的 `.local/environment.toml`，不能把归档占位符当可执行命令。

归档不包含进玩家安装包。当前架构、规格和决策分别位于上一级 ARCHITECTURE、specs 与 DECISIONS；旧记录中的“当前”“下一步”只属于原记录当时的语境。
