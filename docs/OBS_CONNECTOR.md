# OBS 自动录制

## 第一次设置

1. 打开OBS，设置好游戏画面、声音和录制目录，先确认预览正常。
2. 在OBS启用WebSocket服务，记下端口和密码。示例端口是`4455`，以你的设置为准。
3. 在Mod的`tools`目录，将`obs-helper.example.json`复制为`obs-helper.json`，填写相同端口和自己的密码，地址保留`127.0.0.1`。
4. 安装Python 3.11或更新版本，双击`tools/start_obs_helper.cmd`并保持运行。发行包已附WebSocket库；源码用户先运行`tools/setup_python_tools.cmd`。

## 开始录制

在游戏按Ctrl+G，进入“PV工具”的“OBS录制”：

1. 开启“启用OBS联动”，点击“测试OBS连接”，确认认证成功。
2. 开启“PV / 播放列表自动录制”，保存开关，再开始一首新的PV。
3. 先试录一首。录像保存到OBS设置的目录，每首分别保存；播放列表会继续待命。

文件名带`On Vocal`或`Off Vocal`后缀；后者只代表静音状态，不保证音源完全没有歌声。暂停PV时仍会录制；已有人工录制不会被接管。结尾可能含少量结束/加载画面，正式录制前先检查短样片。

## 连不上？

- **Helper未连接**：确认启动器窗口仍在运行，只开一份Helper。
- **OBS连接失败**：检查OBS已启动、WebSocket已开启、端口与密码一致。
- **连接成功但不录制**：确认两个开关都开启，并重新开始一首PV。
- **有文件但没有画面/声音**：检查OBS捕获源和音轨，Mod不会替你设置它们。

`obs-helper.json`只留在自己的电脑。反馈问题时发报错或相关日志片段，不要发密码。
