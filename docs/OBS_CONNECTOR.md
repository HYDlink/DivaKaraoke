# 用 OBS 按歌曲录制

OBS 录制是可选功能。它需要 **OBS 本身、独立 Helper、游戏内联动开关** 同时就绪；只开启游戏面板里的开关不会启动 OBS。

## 第一次连接

1. 打开 OBS，先设置好录制场景、游戏画面、声音、编码和保存目录。确认 OBS 预览中能正常看到、听到游戏。Mod 不会替你选择场景或编码器。
2. 在 OBS 的 WebSocket 服务器设置中启用服务，记下端口和密码。Helper 使用 WebSocket 5；示例端口为 `4455`，以你的 OBS 设置为准。
3. 在 Mod 的 `tools` 目录，把 `obs-helper.example.json` 复制为 `obs-helper.json`。填写相同端口和你自己的 OBS 密码，地址保持 `127.0.0.1`。
4. 确认已安装 Python 3.11 或更新版本。双击同一目录的 `start_obs_helper.cmd`，保持这个窗口运行；不要同时打开多份 Helper。
5. 在游戏按 Ctrl+G，找到“PV 工具”里的“OBS 录制”，勾选“启用 OBS 联动”，点击“测试 OBS 连接”。看到“OBS 已连接，认证成功”后再继续。

`obs-helper.json` 只属于你自己的设备，不要上传到 Git 或发在问题截图里。发行包和源码仓库只提供密码为空的示例。

源码用户若提示缺少 WebSocket 库，先运行 `tools/setup_python_tools.cmd`；发行包已附带该运行库。

## 开始录制

1. 确认 OBS 当前没有你手动开始的录制。
2. 勾选“PV / 播放列表自动录制（持续待命）”，点击“保存 OBS 开关”。
3. 从游戏正常开始一首 PV。播放开始后，观察 OBS 的录制状态和游戏面板提示。
4. 歌曲结束后会停止并保存；保持待命时，下一首会另建一个文件。先试录一首，确认画面、声音和保存位置正确，再使用播放列表。

录像保存到 **OBS 已设置的录制目录**，不是 Mod 目录。文件名按曲名附加 `On Vocal` 或 `Off Vocal`；重名时追加序号。`Off Vocal` 只表示 Mod 的人声静音状态，不保证音源中完全没有残留歌声。

## 需要知道的行为

- 暂停 PV 时仍会继续录制；需要删掉停顿时，请后期剪辑。
- 已经存在的人工录制不会被本功能接管。你手动停止或重启后，同一 PV 不会再次强行接管。
- 关闭自动录制或联动时，只尝试停止本功能自己启动的录制。
- 不保证结束画面或切歌加载画面零帧进入录像。重要录制请先检查短样片。

## 连接失败怎么办

| 看到的提示 | 先检查什么 |
| --- | --- |
| Helper 未连接 | `start_obs_helper.cmd` 是否正在运行，是否误开了另一份旧 Helper |
| OBS 连接失败 | OBS 是否已启动，WebSocket 是否开启，端口和密码是否一致 |
| OBS 已有人工录制 | 先在 OBS 完成自己的录制，再开始下一首 PV |
| 开启后没有生成文件 | 是否同时开启联动和自动录制，是否真正开始了新的 PV |
| 有文件但没有画面或声音 | OBS 的场景、捕获源和音轨；这不是联动开关负责的设置 |

需要进一步排查时，查看 Mod 目录的 `obs-runtime.log` 和 `tools/obs-recordings.log`，提供错误提示及操作步骤即可，不要提供 OBS 密码。
