# 使用文档

第一次使用，从[安装与升级](INSTALL.md)开始。

| 要做什么 | 阅读哪一篇 |
| --- | --- |
| 安装、迁移旧配置、确认加载成功 | [安装与升级](INSTALL.md) |
| 连接 OBS、按歌曲自动录制 | [OBS 录制](OBS_CONNECTOR.md) |
| 关闭支持曲目的人声 | [伴奏模式](NON_VOCAL_SUPPORT.md) |
| 调整歌手颜色、纠正歌手标记 | [歌手配色](SINGER_EXPORT_WORKFLOW.md) |
| 从自己的资料生成歌词与注音 | [歌词工具](LYRICS_EXPORT.md) |
| 排查看不到歌词、连接失败等问题 | [常见问题](TROUBLESHOOTING.md) |

开发者从[贡献指南](../CONTRIBUTING.md)和[源码构建](BUILD.md)进入。用户指南不承担开发交接、验收流水或设备配置的职责。
