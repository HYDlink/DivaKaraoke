# 伴奏模式

按 Ctrl+G 打开“PV 工具”，开启 **“伴奏模式 / 关闭人声”**。在歌曲开始前选好模式，播放后听一段主唱明显的部分，确认结果。

这个开关控制游戏音源已经存在的独立人声声道。**它不是 AI 人声分离器。** 歌声已混进伴奏、只有立体声混音或没有独立人声轨时，开关无法把歌声分离出来。

## 如果仍然有歌声

先取消伴奏模式，再开启对比。换唱版本、曲包替换和不同音源可能采用不同分轨方式，不能只凭歌名判断是否支持。和声、吟唱或采样人声也可能留在伴奏里。

录制文件名中的 `Off Vocal` 表示 Mod 请求的人声静音状态，不能作为纯伴奏的质量保证。遇到不支持的音源，可以使用自己有权使用的伴奏版本；不要通过关闭整首音频来代替人声控制。
