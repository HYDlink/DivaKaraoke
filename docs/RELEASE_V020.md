# 发布记录

## v0.2.1

用户指南与本地环境配置维护版，游戏DLL保持不变。清理后的安装包不再递归收录历史文档，日常工具使用自己的私有路径配置。

## v0.2.0

首次独立发布双轨整句歌词、Ruby 日文注音、行级歌手配色、伴奏控制和 OBS 辅助。安装目录与 DLL 名称为 `DivaKaraoke`，保留旧 `freelyrics.toml` 配置兼容。

发布基于第二阶段，不包含逐字/音频模型实验。构建、离线回归、干净目录装载与附件摘要已检查；实际游戏和 OBS 行为仍受音源、曲包与玩家设置影响。

当前使用方式以[用户文档](README.md)为准。历史版本中的开发记录不应当作安装步骤；校验值从对应 [GitHub Release](https://github.com/HYDlink/DivaKaraoke/releases) 获取。
