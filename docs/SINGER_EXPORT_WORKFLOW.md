# 歌手配色与人工标记

## 在游戏里调整颜色

1. 确认歌曲除了 SRT，还存在对应的 `lyrics/PV编号.singers.tsv`。没有歌手标记时使用默认歌词颜色。
2. 按 Ctrl+G，找到“逐行歌手颜色”，开启歌手配色。
3. 调整对应歌手的未唱、已唱颜色及描边/阴影。多人合唱可选择渐变或融合颜色；开启上下双色时改为纵向配色。
4. 通过面板保存歌手设置。颜色保存在 `singer-colors.toml`，不需要修改歌词正文。

自动标记根据角色活动推测，不能保证每行都与实际发声一致。剧情里的无声口型、没有角色动作的演唱等情况可能需要人工修订。

## 生成歌手标记

先按[歌词工具](LYRICS_EXPORT.md)完成路径配置与歌词导出。完整导出包含歌手标记；只想预览歌手结果时，运行 `tools/build_singer_colors.cmd`。

缓存放在本地配置 `output_dir` 下的 `cache`，人工模板放在同级 `manual-singers`。只有需要人工修改时才进入这里，普通使用不必阅读审计 JSON。

## 修正某一行

1. 打开 `manual-singers/PV编号.singers.manual.tsv`。首次生成工具会创建模板，已有模板不会被覆盖。
2. **只改第四列**；保留表头、行号、起止时间及歌词原文。
3. 保存后运行 `tools/apply_singer_marks.cmd`。此操作会重新应用标记并安装，因此先在私有配置中填写你自己的 `install_dir`。
4. 重新进入该 PV，让游戏重新加载歌手文件。

| 第四列 | 含义 |
| --- | --- |
| `auto` | 使用自动结果 |
| `MIK` / `RIN` / `LEN` | 初音 / 镜音铃 / 镜音连 |
| `LUK` / `MEI` / `KAI` | 巡音 / MEIKO / KAITO |
| `LEN,KAI` | 两位歌手参与，使用合唱配色 |
| `-` | 明确保留默认配色 |

其他列与当前歌词不一致时，工具会拒绝应用，防止把标记安到错误的句子上。若你直接手改了安装目录中的旁路文件，安装保护也可能拒绝覆盖；先备份并检查冲突，不要直接删掉保护清单。
