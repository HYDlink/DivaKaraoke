# 歌词与旁路数据

- 歌曲以 PVID 绑定时间线；切歌、重新开始及无效数据必须清理旧绑定，不能显示上一首内容。
- SRT 提供行级时间与正文。Ruby 和歌手数据必须与同曲行号、时间或正文约束对应。
- 双轨布局由时间线确定，暂停或重播不依赖上一帧积累；当前公开版按整句时间推进。
- 读音只标注有对应依据的正文跨度，不把未知读音填成已确认结果。
- 歌手活动推断不是音频真值，允许未知或人工修订；多人身份归并不能制造复制角色合唱。
- 数据缺失或无效时走明确回退，不假造下一句、词级时间或歌手身份。
- 安装前完整校验新文件和旧所有权；发现用户修改或冲突时拒绝整批覆盖。
- 设备路径、源文件快照和逐曲审计属于生成输入或报告，不是用户操作指南。
