# 文档与本地环境

- README 面向第一次接触项目的使用者，链接目标必须是可直接执行的当前用户指南。
- 用户指南写前提、操作、预期结果和常见失败处理；不要求读者理解某次会话或维护者设备。
- 公共说明和示例不含个人绝对目录。真实目录进入 `.local/environment.toml`；例外如必须存在的平台系统约定，应写发现方式而非个人安装位置。
- 显式命令行参数优先于本地配置；默认值只允许公开的相对目录。
- 本地配置中的安装目录不构成安装授权；只有明确选择安装或应用操作才写目标。
- 私有来源清单必须与同一配置中的游戏目录绑定，不按固定的维护者游戏路径判断。
- STATUS、PLAN 和交接文件保存当前摘要；详细过程不通过不断前插或追加进入这些文件。
- 历史归档明确标注过期用途，不作为 README 用户操作入口，也不随玩家安装包分发。
