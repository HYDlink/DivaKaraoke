# DivaKaraoke v0.2.1

这是文档与离线工具维护版，游戏DLL与v0.2.0一致，不增加运行时功能。

- 重写安装、OBS、伴奏、歌手配色及歌词工具指南，移除用户入口中的研发流水和维护者目录。
- 实际目录集中到不提交Git的.local/environment.toml，仓库只提供无个人路径模板；日常工具与Agent共用该入口。
- 工具取消对维护者游戏路径的判断，普通导出不会自动安装；明确的安装/应用操作才写入目标。
- 玩家安装包使用用户文档和日常工具白名单，不包含历史归档、开发交接、本地配置或私人备份。
- 保留有价值的历史研究和原始记录，当前操作以新版用户指南为准。

从[安装指南](https://github.com/HYDlink/DivaKaraoke/blob/main/docs/INSTALL.md)开始。已有歌词缓存和游戏配置不需要重算；升级工具前备份自己修改的文件，不覆盖自己的OBS私人配置。
