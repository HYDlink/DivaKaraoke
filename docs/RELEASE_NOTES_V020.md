# DivaKaraoke v0.2.0

提供双轨整句歌词、日文注音、歌手配色、伴奏控制及 OBS 辅助录制。

下载对应安装 ZIP，安装至自己的游戏 `mods` 目录；详见[安装指南](https://github.com/HYDlink/DivaKaraoke/blob/main/docs/INSTALL.md)。旧 MMFreeLyrics 目录可以保留，但同时启用未做兼容验收，建议每套配置只启用一个。

不包含逐字时间实验。歌曲缓存由用户迁移或从自己拥有的资料生成；伴奏与自动配色存在音源和场景限制，见用户指南。字体和工具依赖随包附许可证，用户密码、个人目录和原始游戏资源不作为公开分发内容。
